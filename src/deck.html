Slop is code that arrives faster than anyone reads it, understands it, or proves it works.

“They all looked good. They were formally correct. Tests and checks passed.” (tldraw, on the AI pull requests it closed)

  • tests that prove nothing, almost-right code
  • security holes, ignored conventions, unwritten decisions

La tesi di stasera: si può fare vibe coding senza slop. Ma prima, cos'è lo slop. Non è una forma del codice: è come il codice arriva. Arriva più in fretta di quanto qualcuno lo legga, lo capisca o dimostri che funziona.

A security test that is exhaustive by construction

apps/api/src/test/membership-lost.test.tstest('every GET route has a case, and every case is a GET route', () => {
  const routes = createApp()
    .routes.filter((r) => r.method === 'GET')
    .map((r) => `GET ${r.path}`)
  const covered = [...Object.keys(ROUTES), ...Object.keys(NOT_OWNED)]

  expect(routes.filter((r) => !covered.includes(r))).toEqual([])
  expect(covered.filter((c) => !routes.includes(c))).toEqual([])
})

Five things to copy on Monday

  1. Build the gate before the first feature.Slop arrives faster than anyone checks it.
  2. Turn each rule into lint or a test, with a message written for the agent.Ignored conventions, complexity.
  3. Watch every test fail before you trust it.Tests that prove nothing.
  4. Have a fresh agent review at every boundary.Almost right; more code than anyone can read.
  5. Let the agent grill you, and write the answers down.Decisions nobody wrote down, and an agent that forgets between sessions.

Se lunedì volete provarci, ecco cinque cose da copiare. Ognuna risponde a un sintomo dello slop.

  • 0:20 Il gate prima della prima feature: il mio primo commit non aveva feature, solo regole.
  • Ogni regola diventa lint o test, con un messaggio scritto per l'agente.
  • Ogni test visto fallire. Una review fresca a ogni confine. E fatevi interrogare, e scrivete le risposte.

Si può fare vibe coding senza slop. Non perché l'agente sia bravo, ma perché il progetto non accetta codice che non si dimostra da solo.

  • 5.2% to 21.7% of suggested packages did not exist (USENIX Security 2025): register one and wait.
